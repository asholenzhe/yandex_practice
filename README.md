# Playlist Maker Android

Учебный проект из курса Практикума. Приложение реализовано на Jetpack Compose c поддежкой Clean Architecture и навигации через `NavHost`.

## Как собрать
- Среда разработки: Android Studio Ladybug или новее.
- Версия JDK: 17 (ставится вместе с Android Studio).
- Команда сборки: `./gradlew assembleDebug`.
- Минимальная поддерживаемая версия Android — 7.0 (API 24).

## Рабочий процесс
- Главная ветка — `main`. Для работы над спринтом создаётся ветка `sprint-X`.
- После выполнения задач спринта ветка вливается в `main`, ставится тег `vX.0`.
- Чек-листы самопроверки находятся в папке `checklists/`.
- Все тексты кнопок и пользовательские строки лежат в `strings.xml`.

## Изменения по спринтам
- **Sprint 3** — настройка репозитория, базовый экран и переходы между экранами.
- **Sprint 4** — вёрстка поискового и экранов настроек, интенты шаринга и обратной связи.
- **Sprint 5** — внедрён NavHost, добавлены состояния экрана поиска, реализована Clean Architecture для слоя поиска.

## Стек
- Kotlin + Jetpack Compose (Material 3).
- Navigation Compose + ViewModel + StateFlow.
- Коррутины для фоновых операций.
